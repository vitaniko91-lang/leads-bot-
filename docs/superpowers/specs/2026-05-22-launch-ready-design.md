## 1. Контекст

Весь код 4 итераций закоммичен (MVP → стабилизация → дашборд → smart features). Бот успешно запускался один раз 11 мая, поймал 5 тестовых лидов, сгенерил 4 драфта, использовал A/B-шаблоны. После этого простой 11 дней.

**Что блокирует запуск (по убыванию важности):**
1. **Данные:** только 1 тестовый канал в `sources`, профиль был placeholder (исправлено в этой сессии)
2. **Хостинг:** VPS не заказан, deploy на Hetzner отложен до подтверждения боевого качества
3. **Эксплуатация:** smoke E2E с реальным каналом ни разу не прогонялся

Stack изменений в этой сессии: только данные и конфиг, **никаких изменений кода**.

## 2. Решения

### 2.1 Локально → потом VPS

Запуск локально первый. VPS откладываем до подтверждения что бот реально ловит лиды и драфты качественные.

**Why:** код стартовал один раз — фундамент рабочий. Главный риск не технический («бот падает»), а информационный («реальные каналы дают шум вместо лидов» или «фильтр пропускает мусор»). Это видно только на живых данных. Платить €4/мес и тратить полдня на VPS-настройку до того как убедились что бот делает что-то полезное — преждевременно.

**Trade-off:** ночью комп спит → лиды теряются. Принимаем для первой недели как плату за быстрый сигнал.

### 2.2 Discovery вместо ручного поиска каналов

Пользователь не знает фриланс-каналов вручную. Полагаемся на встроенный `DiscoveryScheduler.scan_now()` (iter 4).

**Why:** discovery-модуль уже написан и тестировался. 16 гео-таргетированных запросов с RU-блоклистом. Telethon `contacts.SearchRequest` возвращает каналы по ключевикам. Дайджест с inline-кнопками `[Add]/[Reject]` уже работает.

**Trade-off:** discovery может найти 0 хороших кандидатов на первом проходе. Митигация — ручной google и `/sources add @link` как фоллбэк.

### 2.3 Тон и позиционирование

- Niche: **Web design for AI / SaaS startups** (узкая, подкреплена AXON-кейсом)
- Min budget filter: **$500** (компромисс между шумом и кругозором)
- Tone: **friendly first-person warmth + opinionated typographic confidence**
- Portfolio URL: **behance.net/56wnbww4xp93e7** (личный сайт ещё в Figma, не задеплоен)

### 2.4 Шаблоны откликов — defaults без изменений

Дефолтные 3 A/B-варианта в `templates.example.json` хорошо продуманы. Используем как есть. Калибровка через дашборд после первых 10-20 ответов клиентов.

**Why:** не знаем что работает пока не запустим. Преждевременная оптимизация шаблонов = угадывание.

### 2.5 Timezone — Europe/Kiev

Текущий `Asia/Bangkok` — артефакт прошлой настройки. Меняем на `Europe/Kiev` (Одесса), потому что `DIGEST_TIME=08:15` и `QUIET_HOURS=23:00-08:00` должны жить в твоём часовом поясе.

### Фаза 1 — Холодный старт локально (15 мин)

- [ ] `alembic upgrade head` (схема актуальна, но safe)

- [ ] Verify reconnect: выключи Wi-Fi на 30 секунд, проверь что в логах появилось переподключение, а не висяк

### Фаза 2 — Ad-hoc discovery (30-60 мин)

Discovery встроен, но запускается раз в неделю по расписанию (воскресенье). Для первого запуска нужен ad-hoc trigger.

- [ ] Создать `scripts/run_discovery_once.py`:
  ```python
  # imports + setup
  async def main():
      # bootstrap session, bot, scheduler factory
      n = await scheduler.scan_now()
      print(f"Inserted {n} candidates")
      await scheduler.send_digest_now()
  ```
- [ ] Запустить (с живым ботом!): `uv run python scripts/run_discovery_once.py`
- [ ] В личке у `@vita_leads_bot` получить дайджест-сообщения с карточками
- [ ] Пробежаться, нажать `[➕ Add]` на 5-15 хороших каналах
- [ ] Verify: `SELECT title, region FROM sources WHERE status='active'` — должно быть 5-15 строк

**Fallback если discovery даёт 0 кандидатов:**
- Google «freelance design jobs telegram channel ukraine», добавить вручную через `/sources add @<link> ua uk`

### Фаза 3 — Боевое наблюдение (24-72 часа)

- [ ] Бот живой, listener подцепил новые источники (Telethon auto-resubscribe)
- [ ] Ждём первый пост в одном из каналов
- [ ] Получаем карточку лида в личке
- [ ] **Smoke E2E на первом лиде:**
  - [ ] Смотрим: бюджет, релевантность, гео — фильтр сработал?
  - [ ] Драфт читается как ты?
  - [ ] Жмём ✏️ → правим текст → подтверждаем
  - [ ] Жмём ✅ → ждём антибан-задержку (30-90с) → проверяем что в исходном канале сообщение появилось от @Vita_webdesigner
  - [ ] В дашборде (если поднят) — карточка лида с пометкой "sent"
- [ ] Логируем впечатления (через 5-10 лидов): что фильтр пропускает зря, какие шаблоны звучат не так

### Фаза 4 — Калибровка (по факту)

Триггеры и реакции:

| Симптом | Действие |
|---|---|
| ≥30% карточек нерелевантны | Поднять `MIN_RELEVANCE_SCORE` с 60 до 70 |
| <1 лида в день при 10+ каналах | Понизить `MIN_RELEVANCE_SCORE` до 50, либо понизить `MIN_BUDGET_USD` до 300 |
| Драфт упоминает не тот кейс | Уточнить `tags` в profile.json |
| Шаблон A не выигрывает | Редактируем через `/api/templates` PATCH, либо в дашборде |
| Канал даёт только шум | `/sources pause <id>` |
| Healthcheck алертит часто | Увеличить `HEALTHCHECK_FAILURE_THRESHOLD` с 3 до 5 |

### Фаза 5 — Решение про VPS (через 5-7 дней)

**Go signal на VPS:**
- ≥3 реальных квалифицированных лида за неделю
- ≥1 клиент ответил на твой draft
- Healthcheck стабилен
- Драфты ≥70% уходят без правок

**Если go:**
- Hetzner CX22 (€4/мес), Ubuntu 24.04
- `git clone leads-bot- → cp .env → docker compose up -d`
- Каддy → домен → дашборд по HTTPS
- Бэкап скрипт через host cron (уже готов в `scripts/backup.py`)

**Если не go:** новая итерация по обнаруженным проблемам, без VPS.
